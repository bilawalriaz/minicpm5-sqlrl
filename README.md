# MiniCPM5 SQL RL

Train MiniCPM5-1B as a SQLite agent with MLX, LoRA, group-relative policy gradients,
a verified teacher, and an adaptive SQL curriculum. The local dashboard shows
training metrics and rollout transcripts.

See [sqlrl/README.md](sqlrl/README.md) for setup, the answer protocol, verification,
evaluation, and training commands.

Source code, tests, dependency versions, and engineering results are tracked here.
Model weights, credentials, databases, and checkpoints stay local.
